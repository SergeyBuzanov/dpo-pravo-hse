# Центр ДПО · Факультет права НИУ ВШЭ

Статический сайт центра дополнительного профессионального образования факультета
права НИУ ВШЭ: лендинги, каталог программ и локальная админка для его обновления.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Единственный лендинг ДПО (Design-версия, React-бандл из Claude Design) |
| `Каталог программ.html` | Витрина программ ДПО: карточки со ссылками на страницы программ на hse.ru, фильтры по типу и формату |
| `Клуб выпускников (standalone).html` | Отдельный лендинг клуба выпускников |
| `admin.html` + `admin-server.js` | Локальная админка для обновления каталога в один клик |

## Обновление каталога программ

Каталог тянет данные из живого каталога hse.ru (факультет права, `orgUnit=22753`).

**Из терминала:**
```bash
node update-catalog.js
```

**Через админку (кнопка «Обновить»):**
```bash
node admin-server.js
# затем открыть http://127.0.0.1:5178/admin.html
```
Логин/пароль печатаются в терминал при первом запуске и хранятся в
`.admin-credentials.json` (в git не попадает). Сервер слушает только `127.0.0.1`.

Скрипт разбирает встроенный в страницу hse.ru JSON, обновляет карточки, фильтры,
дату обновления и микроразметку Schema.org `Course` (JSON-LD). Требуется Node 18+
(используется нативный `fetch`, npm-зависимостей нет).

## Шрифты

Все страницы используют фирменные шрифты НИУ ВШЭ — **HSE Sans** и **HSE Slab**
(файлы взяты с hse.ru), размещённые локально в `fonts/`. Внешних запросов к
Google Fonts или иным CDN нет — данные посетителей не покидают сайт (152-ФЗ).
Фолбэки: IBM Plex Sans / Source Serif 4 / Inter / PT Serif (тоже локальные).

## Безопасность

- **Админ-сервер**: HTTP-авторизация (пароль в `.admin-credentials.json`, в git не
  попадает), блокировка перебора паролей (5 ошибок → 15 минут), общий анти-бот
  троттлинг (120 запросов/мин с IP → 429), отсечение сверхдлинных URL (414),
  заголовки `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy` /
  `Cache-Control: no-store`, CSP, защита от path traversal, слушает только
  `127.0.0.1`.
- **Страницы**: Content-Security-Policy и Referrer-Policy через meta-теги;
  email-адреса собираются JavaScript'ом из data-атрибутов — в исходном HTML их
  нет, спам-боты их не соберут.
- **Данные с hse.ru**: URL программ валидируются (только `https://*.hse.ru`),
  весь текст экранируется — компрометация источника не даст XSS.
- При публикации на реальном хостинге DDoS/бот-защиту уровня сети (WAF,
  Cloudflare/DDoS-Guard/защита хостера) нужно включать на стороне хостинга —
  статические страницы сами по себе от этого не защищают.

## Соответствие законодательству

- **152-ФЗ**: без согласия сайт не ставит cookies и не собирает данные; шрифты и
  ресурсы локальные (нет передачи данных третьим лицам и за рубеж). Политика —
  `privacy.html` (ссылки в футерах). Перед публикацией текст политики должен
  утвердить оператор (юридическая служба).
- **Cookies / Яндекс.Метрика**: на страницах ДПО работает баннер согласия
  (`js/cookie-consent.js`): Метрика и её cookies включаются только после
  «Принять», отказ запоминается. **Чтобы включить счётчик, впишите его номер
  в `js/cookie-consent.js` (переменная `METRIKA_ID` в начале файла)** — пока
  он не задан, баннер работает, но счётчик не грузится и cookies не ставятся.
  Вебвизор отключён сознательно (избыточный сбор данных).
- **Доступность** (Приказ Рособрнадзора № 831, ГОСТ Р 52872-2019): на публичных
  страницах есть версия для слабовидящих (кнопка «Аа» в шапке: белый фон, чёрный
  текст, крупный шрифт, без декора), `lang="ru"` на всех страницах.
- **Сведения об образовательной организации**: обязательный раздел ведёт на
  официальный `hse.ru/sveden/` (ссылки в футерах) — витрина не подменяет
  официальный сайт образовательной организации.

## SEO

Мета-теги, Open Graph и микроразметка уже проставлены. Перед публикацией на реальном
домене **замените `https://example.com`** в `canonical`/`og:url` страниц, а также в
`robots.txt` и `sitemap.xml` на реальный адрес.

> Примечание: контент `index.html` рендерится через JavaScript, но базовые
> SEO-меты (title, description, canonical, OG, JSON-LD организации) зашиты
> статически во внешний head — поисковики видят их без выполнения JS.
> Прежний статический лендинг-дубль лежит в `archive/` и в публичный набор
> не входит.

## Осознанные решения релиза

- **Фото в бандле**: hero-фото главной зашито в файл (index.html ≈ 2,65 МБ) —
  решение владельца в пользу полной самодостаточности файла. Оптимизированный
  images/hero-justice.jpg (180 КБ) лежит в репо и используется как og:image;
  при необходимости ускорить мобильную загрузку фото можно вынести из бандла.
- **CSP на главной** отсутствует намеренно: React-рантайм бандла живёт на
  inline/blob-скриптах — задать CSP лучше заголовками хостинга после публикации.

## Замечания по деплою

- `admin-server.js` — это Node-сервер и работает только локально; на статическом
  хостинге (например, GitHub Pages) запустится только сама вёрстка страниц.
- Имена файлов с пробелами/кириллицей корректно открываются (браузер кодирует URL).
