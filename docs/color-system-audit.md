## 6. Отдельно: `{{ accent }}` – это не незаменённый литерал

В задаче он назван незаменённым. Проверка показала обратное, и это меняет вывод,
поэтому фиксирую отдельно.

`{{ accent }}` встречается **34 раза**, все 34 – в `index.html:409`, внутри
`<script type="__bundler/template">`. Этот тег браузер не рендерит: его содержимое
разбирает `js/bundle/dc-runtime.js`, где интерполяция задана регуляркой
`\{\{([\s\S]+?)\}\}`. Значение приходит из компонента лендинга:

```js
const accent = this.props.accentColor ?? '#1658DA';   // строка 2951 раскодированного шаблона
const accentDark = this.darken(accent, 0.22);
return { accent, accentDark, /* … */ };                // строка 2956
```

То есть это **живая привязка**, а не сломанная подстановка. В отрисованном
документе на её месте стоит `#1658DA` (или значение пропса `accentColor`, если
его передадут). Скриншот продакшена подтверждает: кнопка «Записаться» и логотип
«Право» синие, фокус синий. Утечки текста `{{ accent }}` в DOM нет – в `<noscript>`
он не попадает.

Практические следствия:

1. **Заменять `{{ accent }}` на хекс или на `var(--accent)` нельзя** – это
   уничтожит перекрашиваемость лендинга через `props.accentColor`. Единственная
   осмысленная правка – заставить рантайм-значение и CSS-токен ссылаться на один
   источник, а не жить параллельно.
2. Мост уже наполовину построен: на `.dpo-scope` объявлен
   `--dpo-accent: {{ accent }}` (строка 1627). Переменная объявлена, но по ней
   **никто не красится** – все 33 остальных места подставляют `{{ accent }}`
   напрямую. Правильная развязка: оставить одно объявление
   `--dpo-accent: {{ accent }}`, а в остальных 33 местах писать
   `var(--dpo-accent)`. Тогда рантайм-проп остаётся хозяином значения, а CSS
   получает единую точку.
3. Рядом живут `{{ accentDark }}` (5), `{{ radiusSm }}` (9), `{{ radiusMd }}` (7),
   `{{ radiusLg }}` (5) – тот же механизм, та же логика.

`accentDark` считается функцией `darken(accent, 0.22)`, которая возвращает
`rgb(R, G, B)` строкой. От `#1658DA` это даёт `rgb(17, 69, 170)` = `#1145AA` –
ровно тот тёмный синий, что зашит литералом в CSS каталога и в `program.css`.
Значит `#1145AA` в этих файлах и `{{ accentDark }}` в лендинге – одно значение,
посчитанное дважды разными способами.

## 7. Порядок работ

1. Свести четыре `:root` к одному словарю имён (раздел 5, последняя таблица).
   Значения не меняются, риск нулевой.
2. Ввести 7 токенов и прогнать замены по `js/*.js`, `programs/program.css`,
   `Каталог программ.html`, `admin.html`, `privacy.html`, `ratings.html`,
   `404.html`. Лендинг не трогать.
3. Развязать `{{ accent }}` через `var(--dpo-accent)` (раздел 6, пункт 2).
4. Лендинг – только вместе с переписыванием фронтенда: инлайн-стили лежат в
   закодированной строке, правка их вручную нечитаема в diff.
