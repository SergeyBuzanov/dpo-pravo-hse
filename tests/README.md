# Смоук-тест сайта ДПО

Автоматическая проверка ключевых сценариев публичных страниц перед релизом —
вместо ручного обхода в браузере. Playwright + headless Chromium.

## Запуск

```bash
tests/run.sh
```

При первом запуске сам создаёт локальное окружение (`.venv-tests`, через `uv`)
и ставит Playwright + Chromium. Требуется только [uv](https://docs.astral.sh/uv/);
Node не нужен. Выход `0` — всё прошло, `1` — есть провалы (годится для CI).

## Что проверяется (28 проверок)

**index.html** (главная, React-бандл Claude Design): заголовок вкладки, favicon,
theme-color, шрифты HSE, отрисовка hero-фото, версия для слабовидящих (вкл/выкл
**и работа после ре-рендеров** — сторож исправленного бага), куки-баннер (показ +
запоминание отказа), сборка email из data-атрибутов, юридические ссылки в футере,
отсутствие ошибок в консоли, **нет битых ресурсов** (4xx/5xx), **ноль внешних
сетевых запросов** (152-ФЗ).

**Каталог программ.html**: число карточек (≥17), наличие и работа фильтров,
favicon, ссылка «← На лендинг», консоль, битые ресурсы, ноль внешних запросов.

**privacy.html**: заголовок, версия для слабовидящих, функция сброса
cookie-согласия, сборка email, консоль, битые ресурсы.

Проверка «нет битых ресурсов» проверена негативным контролем — она действительно
ловит 404, а не всегда зелёная.

## Замечания

- Каждая страница открывается в свежем контексте (чистый `localStorage`), поэтому
  куки-баннер показывается и его сценарии воспроизводимы.
- Админка (`admin-server.js`) в смоук не входит — это локальный инструмент с
  авторизацией; её регрессия покрывается отдельно (curl-проверки auth/обновления).
- Окружение `.venv-tests/` в git не коммитится.
